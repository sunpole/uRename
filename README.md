Небольшая утилита для Windows: переименовывает файлы из текстового списка по понятной маске. Сохраняет папки и расширения, переводит русские буквы в латиницу и проверяет будущие имена перед запуском. Работает локально, без сторонних библиотек и отправки данных.

> Lightweight Windows batch file renamer with smart numeric padding, Russian transliteration, case-sensitive masks and a dry-run preview. Python standard library only.

## Как это выглядит

Маска `99_999_Aaaaaaaa`:

| Исходное имя | Новое имя |
| --- | --- |
| `1_15_Цефадин.pdf` | `01_015_Tsefadin.pdf` |
| `15_Цефадин.pdf` | `015_Tsefadin.pdf` |
| `11_144_Инструкция Цефадин.pdf` | `11_144_Tsefadin.pdf` |

Последний пример использует режим `!инструкция`.

## Быстрый старт

1. Установите **Python 3.9+ для Windows** с доступной командой `python`.
2. Скачайте `uRename-vX.Y.Z.zip` из [Releases](https://github.com/sunpole/uRename/releases/latest) и распакуйте в отдельную папку.
3. Откройте `files.txt` и вставьте полные пути к файлам — по одному на строку. Кавычки из «Копировать как путь» подходят.
4. Настройте `mask.txt` по примеру ниже.
5. Откройте `preview_rename.bat`, чтобы проверить результат.
6. Откройте `run_rename.bat`, чтобы переименовать файлы.

При скачивании исходников вместо готового ZIP первый запуск создаст `files.txt` и `mask.txt`. Он не выполняет переименование: заполните настройки и запустите программу снова.

## Маска

```text
99_999_Aaaaaaaaaa
!инструкция
```

| Символ | Значение |
| --- | --- |
| `9` | Цифра: `99` превращает 1 в 01, `999` — 15 в 015 |
| `A` | Одна заглавная латинская буква |
| `a` | Одна строчная латинская буква |
| `_` | Разделитель между найденными частями |

- Начальные номера заполняют числовые блоки **справа**. Если номер один, первый блок `99` пропускается вместе с разделителем.
- Если номеров больше, чем блоков, берутся последние начальные номера.
- Числа после начала текста не заполняют начальные числовые блоки.
- Каждый буквенный блок берёт **одно слово**. Для двух слов: `999_Aaaaaaaa_Aaaaaa`.
- Длинные слова обрезаются после транслитерации. Короткие не дополняются.
- Если номер не помещается, программа останавливает запуск и предлагает добавить `9`.
- Строка `!инструкция` удаляет целое русское слово «инструкция» во всех падежах и числах. Регистр не важен. `# !инструкция` отключает режим. Составные слова вроде «видеоинструкция» сохраняются.
- `A` и `a` в маске должны быть латинскими.

## Командная строка

```powershell
python -X utf8 -B uRename.py --init
python -X utf8 -B uRename.py --preview
python -X utf8 -B uRename.py
python -X utf8 -B uRename.py --version
```

Пути к настройкам всегда отсчитываются от папки программы. Относительные пути внутри `files.txt` — от папки этого файла. Первая и третья команды различаются: `--init` только создаёт отсутствующие настройки; запуск без аргументов выполняет переименование.

## Что программа проверяет

До первого изменения проверяется весь список: существование файлов, совпадения новых имён, занятые пути, пустые или запрещённые Windows-имена, переполнение номеров. Папки и символические ссылки отклоняются; дубли входных строк обрабатываются один раз.

**Пакет не является транзакцией.** Сбой сети или прав доступа во время работы может оставить часть файлов переименованной. Результат каждой операции выводится в окно. Автоматического отката нет. После переименования обновите пути в `files.txt`: программа его не переписывает и не угадывает соответствие старых путей новым.

Реальное переименование поддерживается в Windows. На других ОС доступен только просмотр; проверка и изменение регистра зависят от файловой системы.

## Приватность

`files.txt` и `mask.txt` — личные настройки, исключённые из Git. В репозитории лежат `files.example.txt` и `mask.example.txt`. Сборка ZIP использует только явный список публичных файлов и никогда не берёт рабочий список путей. Программа не обращается к сети самостоятельно: сетевые папки доступны средствами Windows.
