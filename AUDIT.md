# Аудит перед публичным выпуском

Дата: 2026-09-15. Область: uRename, настройки, тесты, сборка ZIP, версии и конфигурация публикации. Это прикладной аудит, не сертификация безопасности.

## Результат

На локальной Windows с Python 3.13 пройдены 25 автоматических проверок. Исходные 19 тестов сохранены, добавлены проверки первого запуска, версии, сохранения личных настроек, сборки архива, синхронизации метаданных и генерации сайта. GitHub Actions проверяет проект на Windows с Python 3.9, 3.13 и 3.14; фактические результаты доступны в [Actions](https://github.com/sunpole/uRename/actions).

## Найдено и устранено при подготовке

| Приоритет | Наблюдение | Решение и проверка |
| --- | --- | --- |
| Высокий | Рабочий files.txt содержал личные пути, непригодные для публичного репозитория | files.txt и mask.txt исключены из Git. Публикуются только примеры. Тест ZIP с искусственными приватными маркерами доказывает, что живые настройки не входят в архив |
| Средний | Новый пользователь не получает корректно настроенную рабочую копию из чистых исходников | Первый запуск и --init создают отсутствующие настройки; тест подтверждает сохранение существующих файлов |
| Средний | os.rename имеет разную семантику замены файла на разных ОС | Реальное переименование ограничено Windows, где занятое назначение не заменяется. Остальные ОС могут использовать --preview |
| Средний | Символическая ссылка принималась как обычный файл | Ссылки отклоняются до начала операций |
| Низкий | Не было единой версии и процедуры выпуска | version.json — источник правды; VERSION.md, CHANGELOG.md, сайт и тег проверяются перед выпуском |

## Подтверждённые свойства

- Один или два начальных номера, заполнение нулями, верхний/нижний регистр, транслитерация.
- Удаление всех падежных форм целого слова «инструкция» без затрагивания частей других слов.
- Проверка списка до первого изменения, обнаружение совпадений и существующих назначений.
- Сохранение содержимого и расширения файла в настоящем тестовом переименовании.
- Предпросмотр не переименовывает файлы; дубли входных путей обрабатываются один раз.
- Автоматические проверки рассинхронизации версий, несовпадающего тега и утечки личных настроек в ZIP.
- Production-код не запускает shell-команды, не выполняет введённый текст как код, не содержит токенов и не отправляет телеметрию.

## Известные ограничения

Пакет не является транзакцией: ошибка сети или доступа после успешных операций оставляет частичный результат. Автоматического отката и журнала восстановления нет. Предпросмотр не резервирует файлы; параллельное изменение исходников другими программами не блокируется. Для критичных данных нужны резервные копии и отсутствие параллельного редактирования.

Список files.txt автоматически не обновляется. Числовые блоки маски берут последние начальные номера; буквенный блок берёт одно слово, дефис разделяет слова. Это текущий контракт, а не попытка семантически распознать названия документов.

Длина имени ограничена 255 единицами UTF-16; ограничения полной длины пути, прав и особенностей SMB сообщает Windows. Кириллица транслитерируется по встроенной таблице; полноценная транслитерация всех языков не заявляется. Символические ссылки запрещены, но программа не предназначена для работы с каталогом под управлением недоверенного параллельного процесса.

Удалённые SMB-сбои, конкурирующие процессы и отключение питания не моделировались. Тестирование не меняет пользовательские документы. Статический сайт — документация, он не получает доступ к локальным файлам и не выполняет переименование в браузере.

## Воспроизведение

```powershell
python -B -m unittest -v
python tools/release.py --check
python tools/build_site.py
python tools/package_release.py
```

Проверки запускаются на временных файлах. Изменение версии и патчноутов описано в [CONTRIBUTING.md](CONTRIBUTING.md).
