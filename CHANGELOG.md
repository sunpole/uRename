## [1.0.0] — 2026-09-15

Первый публичный выпуск

### Added

- Умная маска 9 / A / a / _: нули слева и выравнивание начальных номеров справа.
- Транслитерация русских имён и отключаемое удаление всех падежных форм слова «инструкция».
- Предпросмотр, проверка всего списка, защита от занятых имён и повторных путей.
- Первый запуск создаёт локальные настройки; команда --version показывает текущую версию.
- GitHub Pages, автоматические тесты Windows и сборка переносимого ZIP.
- Единый version.json, генерируемые VERSION.md и CHANGELOG.md, инструмент выпуска версий.

### Fixed

- Числовые блоки не обрезают номера молча.
- Изменение только регистра букв выполняется корректно.
- Личные настройки и сетевые пути исключены из Git и release-архивов.

### Security

- Реальное переименование ограничено Windows, где os.rename не заменяет занятый файл.
- Символические ссылки отклоняются предварительной проверкой.
