uRename — переименование по маске

Документация: https://sunpole.github.io/uRename/
Релизы: https://github.com/sunpole/uRename/releases
Версия: python uRename.py --version (источник: version.json).
При первом запуске из исходников программа создаст настройки из *.example.txt.
Личные files.txt и mask.txt не входят в Git; ZIP содержит безопасные копии.

1. В files.txt вставьте пути к файлам, по одному на строку.
   Кавычки из команды Windows «Копировать как путь» разрешены.
   Относительные пути отсчитываются от папки с files.txt.
2. В mask.txt измените строку с символами 9, A, a и _.
3. preview_rename.bat показывает результат без изменения файлов.
4. run_rename.bat выполняет переименование сразу после проверки списка.

Символы маски (латинские A и a):
9 — цифра. 99: 1 -> 01; 999: 15 -> 015.
A — заглавная буква; a — строчная буква.
_ — разделитель. AAaa даёт две заглавные и две строчные буквы.

Для 99_999_AAAAAAA:
11_15_тексттексттекст.pdf -> 11_015_TEKSTTE.pdf
15_тексттексттекст.pdf    -> 015_TEKSTTE.pdf
тексттексттекст.pdf       -> TEKSTTE.pdf

Начальные номера заполняют числовые блоки справа налево.
Если начальных номеров больше, чем блоков, берутся последние номера.
Числа после начала текста не считаются начальными номерами:
15_текст 20 от 2026.pdf -> 015_TEKST.pdf.
Чтобы взять число после текста, добавьте блок 9 после буквенного блока.

Каждый буквенный блок берёт одно слово по порядку.
99_999_Aaaaaaaa_Aaaaaa может взять два слова: Реплевак Оптима.
Строка !инструкция в mask.txt включает удаление русского слова «инструкция»
и всех его падежных форм в единственном и множественном числе, в любом регистре.
Например: инструкция, инструкции, инструкцию, инструкцией, инструкциею,
инструкций, инструкциям, инструкциями, инструкциях.
Для отключения удалите строку или запишите # !инструкция.
Удаляется только целое слово в имени файла до перевода в латиницу.
Папка, расширение, слова вроде «видеоинструкция» не меняются этим режимом.
При маске 99_999_Aaaaaaaaaa и включённом режиме:
3_#41. Инструкция Ветацеф 200.pdf -> 03_041_Vetatsef.pdf.
Русские буквы переводятся в латиницу ДО ограничения длины.
Короткие слова не дополняются, длинные обрезаются.
Если номер длиннее блока 9, увеличьте блок: цифры не обрезаются.
Расширение и папка файла сохраняются.

Перед запуском проверяется весь список. При пропавшем файле, занятом
имени, слишком длинном номере или совпадении новых имён запуск отменяется.
Повторяющиеся строки списка обрабатываются один раз. Папки не переименовываются.
Символические ссылки отклоняются. Реальное переименование — только Windows.
Сбой доступа или сети уже во время работы может оставить часть файлов
переименованной; результат каждого действия выводится в окне.

files.txt автоматически не меняется. Для нового запуска скопируйте актуальные
пути. Программа не угадывает, какой файл соответствует старому пути.
Уже подходящие имена пропускаются; регистр букв при необходимости меняется.

Проверка программы: python -B -m unittest -v test_urename
Требуется Python 3.9 или новее. Сторонние библиотеки не нужны.
