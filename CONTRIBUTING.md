# Участие в разработке

Спасибо за интерес к uRename. Для ошибок используйте Issues с обезличенным примером имени, маской и ожидаемым результатом. Не публикуйте рабочие сетевые пути и конфиденциальные документы.

## Проверка изменений

Используйте Python 3.9+ и Windows. Сторонние библиотеки не нужны.

```powershell
python -B -m unittest -v
python tools/release.py --check
python tools/build_site.py
python tools/package_release.py
```

Меняя правила маски, добавьте пример в тесты. Проверяйте настоящее переименование только в временной папке. Pull request должен объяснять наблюдаемое изменение и проверку.

## Выпуск версии

Используется SemVer: patch для исправлений, minor для совместимых возможностей, major для несовместимых изменений правил или интерфейса.

1. Обновите версию и патчноуты одной командой:
   `python tools/release.py --bump patch --note "Описание исправления"`
   Опцию `--note` можно повторять. При необходимости задайте `--date YYYY-MM-DD`.
2. Проверьте изменения в `version.json`, `VERSION.md` и `CHANGELOG.md`. Для подробной группировки можно отредактировать changes в JSON, затем выполнить `python tools/release.py --sync`.
3. Запустите тесты и `python tools/release.py --check`.
4. Закоммитьте и отправьте изменения в main. Дождитесь зелёного CI.
5. Создайте аннотированный тег `vX.Y.Z`, совпадающий с JSON, и отправьте его на GitHub.

Workflow Release проверит тег, выполнит тесты, соберёт ZIP и SHA256SUMS.txt и опубликует GitHub Release с патчноутами. Повторный запуск не перезаписывает существующий опубликованный релиз. Исправление опубликованного кода требует новой версии.

Сайт GitHub Pages автоматически обновляется из main после проверки файлов версий и тестов. История выпусков берётся из того же JSON.

## Состав проекта

- `uRename.py`: программа.
- `*.example.txt`: публичные начальные настройки.
- `tools/release.py`: версия и журнал изменений.
- `tools/build_site.py`: статический сайт из docs и метаданных.
- `tools/package_release.py`: архив из разрешённого списка файлов.
- `.github/workflows/`: тесты, Pages и Releases.
