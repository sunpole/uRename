# Правила общения

uRename открыт для участников с любым опытом. В Issues, Pull Requests и обсуждениях проекта ожидается уважительное и предметное общение.

## Ожидаемое поведение

- Критикуйте решения и код, а не людей.
- Описывайте ошибки воспроизводимыми примерами и помогайте уточнить непонятное.
- Уважайте различия в опыте, языке, происхождении и взглядах.
- Принимайте обоснованную обратную связь и исправляйте свои ошибки.

## Недопустимое поведение

Оскорбления, дискриминация, угрозы, преследование, сексуализированные материалы, спам и публикация чужих личных данных без разрешения недопустимы. Не переносите конфликты из проекта в личное преследование участников.

## Реакция на нарушения

Сопровождающий проекта — [sunpole](https://github.com/sunpole). Он может попросить изменить сообщение, скрыть неприемлемое содержание, закрыть обсуждение или ограничить участие при повторном либо серьёзном нарушении. Решение должно учитывать контекст и тяжесть ситуации.

Для конфиденциальной жалобы используйте встроенную функцию GitHub «Report content» у сообщения. Не публикуйте личные данные или чувствительные подробности в открытом Issue. Об уязвимостях сообщайте по инструкции в [SECURITY.md](SECURITY.md).

Эти правила применяются в пространствах проекта и при публичном выступлении от его имени.
