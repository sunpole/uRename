01 / БЫСТРЫЙ СТАРТ

Четыре шага.
Имена в порядке.

Нужны Windows и Python 3.9 или новее. Скачайте архив из Releases и распакуйте в отдельную папку.

01

Добавьте файлы

Вставьте пути в files.txt, по одному на строку. Кавычки из «Копировать как путь» подходят.

02

Задайте маску

Откройте mask.txt. Выберите количество цифр, букв и нужный регистр.

03

Посмотрите результат

Запустите preview_rename.bat. Программа покажет будущие имена и проверит конфликты.

04

Переименуйте

Запустите run_rename.bat. После операции обновите пути в списке для следующего запуска.

Скачали исходники? Первый запуск создаст files.txt и mask.txt. Заполните их и запустите программу снова.

02 / ЯЗЫК МАСКИ

Четыре символа.
Много возможностей.

Числа дополняются нулями слева, слова переводятся в латиницу. Каждый буквенный блок берёт одно слово.

9

Цифра

99: 1 → 01
999: 15 → 015

A

Заглавная

Одна заглавная
латинская буква.

a

Строчная

Одна строчная
латинская буква.

_

Разделитель

Подчёркивание между
найденными частями.

Один номер или два? Маска разберётся.

Начальные номера заполняют числовые блоки справа. При одном номере первый блок и лишнее подчёркивание пропускаются.

Маска: 99_999_AAAAAAA

11_15_текст → 11_015_TEKST
   15_текст →    015_TEKST
      текст →        TEKST

Уберите слово «инструкция».

Добавьте отдельную строку !инструкция. Режим удаляет целое слово во всех падежах и числах, независимо от регистра.

99_999_Aaaaaaaaaa
!инструкция

3_41_Инструкция Ветацеф.pdf
→ 03_041_Vetatsef.pdf

Чтобы отключить: # !инструкция. Части слов, например «видеоинструкция», сохраняются.

03 / ПОНЯТНЫЕ ПРАВИЛА

Без сюрпризов
при запуске.

Что проверяется до переименования?

Весь список: существование файлов, занятые имена, совпадения результатов, пустые и запрещённые имена Windows, слишком длинные номера. Папки и символические ссылки отклоняются. Дубли строк обрабатываются один раз.

Что будет, если слово или номер длиннее маски?

Слово обрежется до длины буквенного блока после транслитерации. Номер не обрезается: программа остановит запуск и попросит добавить символы 9. Короткое слово не дополняется.

Как сохранить два слова или число после текста?

Добавьте второй блок: 999_Aaaaaaaa_Aaaaaa для двух слов или 999_Aaaaaaaa_99 для слова с последующим числом. Пробелы и дефисы разделяют слова. Числа после текста не заполняют начальные числовые блоки.

Есть ли автоматический откат?

Нет. При сбое сети или доступа уже во время работы часть файлов может быть переименована. Окно показывает результат каждого действия. Предпросмотр не резервирует имена. Перед новой операцией обновите files.txt.

Куда отправляются имена файлов?

Программа обрабатывает их локально и не отправляет телеметрию. Сетевые папки доступны средствами Windows. Личные files.txt и mask.txt исключены из Git и никогда не используются при сборке публичного ZIP.

Можно ли запустить через командную строку?
python -X utf8 -B uRename.py --init
python -X utf8 -B uRename.py --preview
python -X utf8 -B uRename.py
python -X utf8 -B uRename.py --version

Реальное переименование поддерживается в Windows. На других ОС доступен только просмотр. Запуск от администратора не требуется.
